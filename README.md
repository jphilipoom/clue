## Welcome to Team East Coast's Clue Game

Setup:

Set your editor to auto-format with black or other linting library upon save. In visual studio code, go to file, settings, preferences, format on save.

Install dependencies using pip3 install -r requirements.txt

To update the requirements.txt, you can run pip3 freeze > requirements.txt (only do this for an environment only holding requirements for *just* this project, we don't want unneeded dependencies in here)
